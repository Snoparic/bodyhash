# Changelog

## 1.1.0 — 2026-11-11

### Исправлено
* `extract_body` переписан на потоковую логику в 1.0.0 и молча пропускал ошибки:
  * незакрытый блок (START есть, END нет) давал хеш пустой строки с кодом 0 — теперь код 3 «marker not found»;
  * отсутствующая пара маркеров при повторном `-e` молча игнорировалась — теперь код 3;
  * проверка валидации закомментирована в коде как TODO — реализована (`opened`/`closed` для каждой пары).
* Осиротевший END (без открытого START) больше не учитывается в `--exclude-epilogue`.
* `markers` корректно сообщает END на той же строке, что и START (однострочные блоки).
* Коды возврата приведены к документированным: 4 — файл не найден, 3 — маркеры не найдены (раньше `markers` молча выходил с 1).
* Тесты теперь вызывают `./bodyhash` из рабочей копии, а не установленный бинарник из PATH (раньше `make ci` на чистой машине падал или проверял устаревшую версию).
* Тест «excludes MULTIPLE blocks» теперь реально сравнивает хеши, а не только факт непустого вывода.
* Срезание UTF-8 BOM ломалось в UTF-8-локалях: gawk (например, на ALT Linux с ru_RU.UTF-8) считает BOM одним символом, и байтовое сравнение молча не срабатывало — хеш BOM-файла отличался от хеша файла без BOM. Теперь awk и grep всегда вызываются с `LC_ALL=C` (байтовая семантика независимо от системной локали и реализации awk: gawk/mawk/BSD/busybox), BOM задан октальным литералом внутри awk; добавлен тест, воспроизводящий баг в UTF-8-локали (31 тест).

### Добавлено
* Кроссплатформенность: Linux (GNU), macOS (BSD), Git Bash/WSL.
  * нормализация перенесена из GNU sed в POSIX-awk (BOM, CRLF, пробелы);
  * автоопределение бэкенда: coreutils -> shasum/md5 (macOS) -> openssl;
  * `--indent-tabs` работает и без `expand` (awk-фолбэк с той же математикой);
  * `check` сравнивает ожидаемый хеш без учёта регистра букв.
* Валидация `-e` (формат `START::END`, ровно один `::`, непустые маркеры) и `--indent-tabs=N` — код 2 при ошибке.
* Явные сообщения при пропущенном аргументе `-e`/`-a`.
* Регрессионные тесты: незакрытый блок, вторая пара маркеров, однострочный блок, `--exclude-preamble/epilogue`, `--strict-start`, кейс-независимый `check`, соответствие системным sha256sum/sha512sum/md5sum/b2sum/openssl.

### Изменено
* Версия поднята до 1.1.0; man-страницы и README синхронизированы с поведением.
* Форматы хешей не изменились: хеш того же файла на 1.0.0 и 1.1.0 совпадает (кроме случаев, которые раньше были ошибкой).
